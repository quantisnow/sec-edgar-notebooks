# SEC EDGAR notebooks

Python notebooks that answer questions about SEC filings: Form 4 insider trades, 8-K events, 13F holdings, XBRL financials and House members' stock trades. Each one runs against the [Quantisnow SEC API](https://www.quantisnow.com/sec-api) and opens in Jupyter or Google Colab.

## Run one

1. Get a free API key at https://www.quantisnow.com/sec-api/keys
2. `export QUANTISNOW_API_KEY=...` (in Colab, add it under Secrets and run `os.environ["QUANTISNOW_API_KEY"] = userdata.get("QUANTISNOW_API_KEY")`)
3. `pip install -r requirements.txt` and open the notebook
